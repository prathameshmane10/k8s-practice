# Minikube Cluster Setup and Application Deployment Guide

This guide provides step-by-step instructions for installing **Minikube** on an Ubuntu system, verifying cluster status, deploying an application (Nginx), and exposing it via Kubernetes services.

Minikube allows you to run a single-node Kubernetes cluster locally for development and testing purposes.

---

## Prerequisites

- **OS:** Ubuntu Linux (EC2 / Local machine)
- **Privileges:** `sudo` access
- **Network:** Active internet access
- **Virtualization Support:** Check with the following command:
  ```bash
  egrep -c '(vmx|svm)' /proc/cpuinfo
  # (0 = disabled, 1 or higher = enabled)
  ```

---

## Part 1: Installing Minikube & Prerequisites

### Step 1: Update System Packages
Update package lists to ensure latest dependencies:
```bash
sudo apt update
```

### Step 2: Install Required Packages
Install core utilities needed for downloading binaries:
```bash
sudo apt install -y curl wget apt-transport-https
```

### Step 3: Install and Configure Docker Engine
Minikube uses Docker as its container driver.

1. **Install Docker:**
   ```bash
   sudo apt install -y docker.io
   ```

2. **Start and Enable Docker Service:**
   ```bash
   sudo systemctl enable --now docker
   ```

3. **Configure User Permissions (Non-root Docker execution):**
   ```bash
   sudo usermod -aG docker $USER && newgrp docker
   ```
   *(Note: Log out using the `exit` command and reconnect if group membership doesn't update automatically).*

### Step 4: Install Minikube CLI
Download the latest Linux binary, grant execute permissions, and move it to your system path:
```bash
curl -Lo minikube https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64
chmod +x minikube
sudo mv minikube /usr/local/bin/
```

### Step 5: Install `kubectl` CLI
Download the Kubernetes command-line tool:
```bash
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
chmod +x kubectl
sudo mv kubectl /usr/local/bin/
```

---

## Part 2: Starting and Managing Minikube Cluster

### Step 6: Start Minikube Cluster
Initialize the single-node cluster using Docker as the runtime driver:
```bash
minikube start --driver=docker
```

### Step 7: Verify Cluster Status
Check if the cluster components and control plane nodes are active:
```bash
# Check Minikube process status
minikube status

# Verify node state via kubectl
kubectl get nodes
```

---

## Part 3: Deploying and Testing an Application

### Step 8: Deploy Nginx Application
Create a Deployment manifest directly using `kubectl`:
```bash
kubectl create deployment minikube-nginx --image=nginx
```

### Step 9: Expose Deployment as a Service
Expose the deployment outside the cluster internal network using a `NodePort` service:
```bash
kubectl expose deployment minikube-nginx --type=NodePort --port=80
```

### Step 10: Verify Deployment and Service Status
Ensure the pod is in the `Running` state and the service has assigned ports:
```bash
kubectl get pods
kubectl get svc minikube-nginx
```

### Step 11: Access Application URL
Retrieve the service URL generated by Minikube:
```bash
minikube service minikube-nginx --url
```

Test access directly from your terminal using `curl`:
```bash
curl $(minikube service minikube-nginx --url)
```

---

## Part 4: Lifecycle Management Commands

### Stop Minikube Cluster
Pause all running containers and stop the Minikube virtual environment:
```bash
minikube stop
```

### Delete Minikube Cluster
Completely clean up and remove the Minikube virtual instance:
```bash
minikube delete
```
